# Guitar Combo PWA (Тюнер + Метроном)

Обновлённое PWA-приложение для гитаристов.

## Что нового:
1. **Плавная стрелка тюнера:** стрелка больше не дрожит благодаря математическому сглаживанию (LERP).
2. **Мягкая зелёная подсветка по краям экрана:** загорается при точном попадании в ноту (±3 цента).
3. **Подсказка номера струны:** отображает, какая это струна в стандартном строе (E2, A2, D3, G3, B3, E4).
4. **Встроенный метроном:** с регулировкой BPM (30–250), выбором музыкального размера (4/4, 3/4, 2/4, 6/8) и визульным отсчетом долей.

## Файлы:
- `index.html` — разметка с вкладками
- `style.css` — неоновые стили и свечение
- `app.js` — тюнер с плавной анимацией + аудио-метроном
- `manifest.json` — конфигурация PWA
- `sw.js` — оффлайн-режим
