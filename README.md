🎸 tuner.metronom

Простой онлайн-тюнер для гитары и удобный метроном в одном приложении.

🔗 "Открыть tuner.metronom" (https://frongee521.github.io/tuner.metronom/)

✨ Возможности

- 🎸 Настройка гитары через микрофон
- 🎵 Метроном с настройкой темпа
- ✅ Отметки настроенных струн
- 🌐 Русский и английский языки
- 🌗 Светлая и тёмная темы
- 📱 Возможность установить приложение на устройство

🚀 Как пользоваться

1. Открой "tuner.metronom" (https://frongee521.github.io/tuner.metronom/).
2. Разреши доступ к микрофону.
3. Настрой гитару с помощью тюнера.
4. Используй встроенный метроном для занятий.
