# Guitar Tuner PWA

Гитарный точный тюнер в виде Progressive Web App (PWA).

## Файлы в архиве:
- `index.html` — основная разметка
- `style.css` — стили и интерфейс
- `app.js` — логика автокорреляции и определение ноты
- `manifest.json` — манифест для установки PWA
- `sw.js` — Service Worker для оффлайн-работы

## Как запустить:
1. Распакуйте архив.
2. Запустите веб-сервер (например, через VS Code Live Server или локальный сервер Node/Python).
3. Откройте `index.html` и разрешите доступ к микрофону.
