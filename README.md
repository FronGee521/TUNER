# FRET/LAB — Guitar Tuner

Локальный веб-тюнер для гитары: микрофон, оценка частоты, нота, отклонение в cents, калибровка A4 и несколько строев.

## Запуск

Из-за ограничений браузера микрофон обычно работает на HTTPS или localhost.

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Запустите локальный сервер:
   - Python: `python -m http.server 8000`
4. Откройте `http://localhost:8000` и разрешите доступ к микрофону.

Можно разместить папку на любом статическом хостинге с HTTPS.

## Примечание по точности

Алгоритм использует автокорреляцию и сглаживание нескольких измерений. Реальная точность зависит от микрофона, фонового шума, качества звучания струны и устройства. Показание cents — оценка относительно выбранной целевой ноты, не метрологическая гарантия.
